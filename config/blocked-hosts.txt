# ===== 屏蔽域名（一票否决）=====
# 每行一个域名；# 开头为注释。
# 命中规则：该域名本身 + 它的全部子域。
#
# 生效范围（全流程，不是只清产物）：
#   1. 收集层：池子里 / 上游捞来的 / 多仓冒出来的候选地址，命中就不抓
#   2. 整理层：站点的 jar / api / ext / playUrl、直播源的 url、解析的 url，
#      命中就整条剔除，并写进 聚合接口/剔除报告.json（原因里带命中的域名）
#   匹配前会先做 normUrl，所以被 gh-proxy 之类代理套娃藏起来的屏蔽域名也躲不掉
#
# 为什么需要它：产物是每天从上游接口重新生成的，只手工删产物第二天就会长回来。
