> 判定阈值（只看首字节，故意不看吞吐）：普通站 TTFB>1500ms 判慢，内置爬虫站（csp_*）放宽到 3000ms —— 内置站测的是目标站首页，HTML 更重；采集站（type 0/1）精选阈值放宽到 800ms —— cms 后端首字节天然比静态资源慢。
